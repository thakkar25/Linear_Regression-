# 📈 Linear Regression

## What is Linear Regression?

Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value by finding the best-fit straight line between the independent variable (X) and the dependent variable (Y).

The relationship is represented by:

y = mx + c

Where:
- y = Predicted value
- x = Independent variable
- m = Slope
- c = Intercept
